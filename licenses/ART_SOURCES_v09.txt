TechSavvy Arena v0.9 art sources
==============================

Original models
---------------
The authored Kyleverse anatomy/armor modules, five weapons/hands and industrial
environment modules were created locally for this project with Blender 4.5.14.
Reproducible original authoring scripts are retained in the project tools folder.
These are not extracted assets from Borderlands or another commercial game.

Kyle Hearn likeness and TechSavvy branding
---------------------------------------
Used with Kyle's explicit authorization for TechSavvy Arena. Original photos,
including additional front/side references in his authorized private photo
library, remain unchanged. Full private reference photos are not distributed.
The dimensional face is an authored photo-referenced model, not a claim of a
photogrammetry scan. Existing expression artwork remains in the game.

The 2K material albedo, OpenGL normal, roughness, ambient occlusion and optional
metallic channels were downloaded through the public API. File size and provider
MD5 were checked and SHA-256 recorded in the source provenance manifest.
The shipped game works offline and does not use the live Poly Haven API.
API terms reviewed October 14, 2026:
https://github.com/Poly-Haven/Public-API/blob/master/ToS.md

Tools are not part of the game distribution. Blender portable was downloaded
from Blender's official mirror service and its SHA-256 matched the official
release checksum. Blender license: https://www.blender.org/about/license/
